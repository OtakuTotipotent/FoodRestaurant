# FoodRestaurant

A static restaurant website built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. Swiper, Font Awesome, and the Nunito font are loaded from CDNs, so those resources require an internet connection.

## Ordering form

The order form is still front-end only; it does not submit orders to a restaurant or database. A backend or form service is needed for real order processing.
